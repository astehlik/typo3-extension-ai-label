Renders the AI origin marker for the current content record (or, if a FAL "file" argument is passed, for that file) - nothing renders unless the record/file is actually flagged. Arguments: - file (optional): a FAL file reference, e.g. arguments="{file: image}" - record (optional): the tt_content (or other applicable table) row to check, e.g. arguments="{record: record}" - variant (optional, default "black"): one of "black", "black_transparent", "white", "white_transparent" - selects which of the bundled icon sets to use. Projects that ship their own icon set can override this partial via a higher-priority partialRootPaths entry. Not declaring these via f:argument: doesn't exist in TYPO3 v12's bundled Fluid. variant's "default" wouldn't help anyway - it only applies when the argument is completely absent, not when passed as empty/null - hence the truthy check below.
